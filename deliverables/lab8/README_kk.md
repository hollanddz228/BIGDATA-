## 4. 1-бөлім: сатылымдар картасы — Going to the dogs

### 4.1. Деректерді ашу және бағандарды тексеру

1. **File → New** арқылы жаңа есеп ашыңыз.
2. **Home → Get data → Excel workbook** таңдаңыз. Архивтегі файл CSV болса, **Text/CSV** таңдаңыз.
3. Файлды көрсетіңіз. Navigator терезесінде сатылымдары бар кестені және онымен байланысты анықтамалық парақтарды белгілеңіз. **Transform Data** басыңыз.
4. Power Query ішінде мына деректердің қай кестеде екенін анықтаңыз:

| Қажетті дерек | Нұсқаулықтағы баған | Мақсаты |
| --- | --- | --- |
| Қала атауы | `Town` | Картаның орны |
| Аймақ атауы | `RegionName` | Түстер мен срез |
| Сауда орталығы | `CentreName` | Егжей-тегжейлі кесте |
| Сатылған тауар саны | `Quantity` | Қосындысы есептелетін сан |

5. Егер осы төрт дерек бір кестеде болса, сол сұрауды оң жақ батырмамен басып, **Rename → Sales** деп атаңыз. Қала бағаны басқаша аталса, қала атаулары тұрған бағанды **Rename → Town** деп өзгертіңіз. Қалған үш бағанды да жоғарыдағы атауларға сәйкестендіріңіз.
6. `Town`, `RegionName`, `CentreName` үшін **Text**, `Quantity` үшін **Whole number** дерек түрін қойыңыз. `Quantity` ішінде қате мәндер мен мәтіндік қорытынды жолдары болмауын тексеріңіз.
7. **Close & Apply** басыңыз.

**Егер деректер бірнеше парақта болса:** `Quantity` тұрған сатылым кестесін негіз етіңіз. Power Query ішінде **Home → Merge Queries** арқылы оған сауда орталығы, қала және аймақ анықтамалықтарын олардың ортақ кодтары бойынша кезекпен қосыңыз. `Left Outer` біріктіруін таңдаңыз. Әр қосылған бағанның екі жебесін басып, қажет атау бағандарын ашыңыз. Нәтижесінде жоғарыдағы төрт бағаны бар `Sales` сұрауын алыңыз. Кодтардың нақты атауын архивтен тексеріңіз; атау бағандарын кездейсоқ сәйкестендірмеңіз. Анықтамалықтағы кодтар қайталанбауы керек. Әр Merge кейін жол саны мен `Quantity` қосындысы өспегенін тексеріңіз: қайталанған код сатылымды екі рет есептетеді.

Альтернатива ретінде кестелерді бөлек қалдырып, Model view ішінде бірегей кодтан сатылымға қарай `1:*` байланыстар орнатуға болады. Бұл жағдайда төмендегі DAX формуласында қала бағанының нақты кестесін қолданыңыз; срездің сатылым кестесін сүзетінін міндетті түрде тексеріңіз.

### 4.2. Қала мен елді біріктіретін баған

1. `Sales` кестесін таңдаңыз.
2. **Modeling → New column** басыңыз.
3. Формуланы енгізіңіз:

```dax
UK town = TRIM(Sales[Town]) & ", UK"
```

Бұл — есептелетін **баған**, measure емес. Мысалы: `Romford, UK`. Мұндағы `UK` — United Kingdom; тек England сөзін қосу басқа аймақтарды қате орналастыруы мүмкін.

4. `UK town` бағанын таңдаңыз. **Column tools → Data category → Place** қойыңыз. Қалаға ел атауы қосылғандықтан, `Country/Region` санатын бұл бағанға қоймаңыз.
5. Жаңа өлшем жасаңыз: **Modeling → New measure**.

```dax
TotalQuantity = SUM(Sales[Quantity])
```

`Quantity` үшін Count емес, **Sum** керек: тапсырма сатылым жолдарының санын емес, сатылған тауар санын сұрайды.

### 4.3. Картаны құру

1. Бос кенепті басып, **Map** визуалын таңдаңыз. Қазіргі нұсқада Azure Maps ұсынылса, **Azure Maps** арқылы көпіршікті карта жасаңыз.
2. Өрістерді орналастырыңыз:

| Визуал өрісі | Дерек |
| --- | --- |
| Location | `Sales[UK town]` |
| Legend | `Sales[RegionName]` |
| Bubble size / Size | `[TotalQuantity]` |
| Tooltips | `Sales[Town]`, `Sales[RegionName]`, `[TotalQuantity]` |

3. Картаны Ұлыбритания көрінетіндей үлкейтіңіз. Бастапқыда барлық аймақты қараңыз.
4. **Format visual → General → Title** ішіне `Қалалар бойынша сатылған тауар саны` деп жазыңыз.
5. Аймақтар әртүрлі түспен, тауар саны көп қалалар үлкенірек көпіршікпен көрсетілуі керек. Azure Maps қолдансаңыз, көпіршік қабатын қосып, өлшемнің `TotalQuantity` бойынша өзгеретінін тексеріңіз.

### 4.4. Аймақ бойынша срез

1. Кенептің бос жеріне **Slicer** визуалын қосыңыз.
2. Өрісіне `Sales[RegionName]` апарыңыз.
3. Атауын `Аймақты таңдаңыз` деп қойыңыз.
4. `London` және `South East` таңдаңыз. Қажет болса, **Ctrl** ұстап екінші аймақты басыңыз немесе Selection параметрінен **Single select = Off** қойыңыз.
5. Картада тек осы екі аймақтың қалалары қалуы тиіс. Тізімдегі аймақ атауын бастапқы файлда қалай жазылса, солай таңдаңыз.

### 4.5. Сауда орталықтары кестесі және Romford тексеруі

1. **Table** визуалын қосыңыз.
2. Оған `Sales[CentreName]` және `[TotalQuantity]` қосыңыз.
3. Кестенің атауын `Сауда орталықтары бойынша тауар саны` деп қойыңыз.
4. Картада **Romford** қаласының көпіршігін таңдаңыз. Қаланы tooltip арқылы тексеріңіз; Лондон маңындағы жақын нүктені қателеспеңіз.
5. Егер кесте өзгермесе: картаны таңдаңыз → **Format → Edit interactions** → кесте үстіндегі **Filter** белгісін қосыңыз. None белгісі таңдалмауы керек.
6. Түпнұсқа тапсырмадағы үлгі тексеруі:

| Сауда орталығы | Quantity |
| --- | ---: |
| The Brewery | 403 |
| The Liberty Shopping Centre | 343 |
| The Mall Romford | 119 |
| Барлығы | **865** |

`403 + 343 + 119 = 865`. Бұл сандар құжаттағы үлгіден алынды; осы ортада архив бойынша қайта есептелген жоқ. Өз файлыңызда айырма болса, дерек нұсқасын, белсенді сүзгілерді, Sum/Count таңдауды және Merge кезінде көбейген жолдарды тексеріңіз.

### 4.6. Бірінші бөлімді сақтау

**File → Save As** арқылы `C:\BigDATA\lab8\results\Going to the dogs.pbix` сақтаңыз. Есепте кемінде карта, аймақ срезі және сауда орталықтары кестесі болсын. Romford таңдалған көріністің скриншотын сақтаңыз.

## 5. 2-бөлім: Brexit нәтижелері — Red stains

### 5.1. Ресми дауыс беру деректерін жүктеу

1. Бірінші есепті сақтап, **File → New** арқылы екінші есеп жасаңыз.
2. Тапсырмадағы дереккөзі — **UK Electoral Commission**, 2016 жылғы 23 маусымдағы ЕО мүшелігі туралы референдум.
3. Негізгі ресми сайт: <https://www.electoralcommission.org.uk/>. Сайтта `EU referendum results 2016` деп іздеп, жергілікті санау аумақтары бойынша CSV нәтижелерін ашыңыз. Parliamentary constituency бойынша бағаланған деректерді алмаңыз.
4. Ресми CSV үшін құжаттарға байланысты жиі пайдаланылған тарихи мекенжай:

```text
https://www.electoralcommission.org.uk/sites/default/files/2019-07/EU-referendum-result-data.csv
```

Бұл мекенжай осы ортадан тексерілмеді; сайт оны өзгерткен болуы мүмкін. Ашылмаса, ресми нәтижелер бетіндегі қазіргі CSV сілтемесін пайдаланыңыз.

5. **Home → Get data → Web** таңдап, жұмыс істейтін CSV сілтемесін қойыңыз. Алдын ала қарауда `Area`, `Region`, `Leave`, `Valid_Votes` бағандары көрінгенін тексеріп, **Transform Data** басыңыз.
6. Егер Web қосылымы ашылмаса, сол ресми CSV файлын браузерден `part2` бумасына сақтап, **Get data → Text/CSV** арқылы жүктеңіз. Бұл да ресми деректі пайдалану болып саналады. Есепте жүктеу тәсілін және дереккөзді көрсетіңіз.
7. Сұрауды **Brexit** деп атаңыз. `Area`, `Region`, `Area_Code` — Text; `Leave`, `Remain`, `Valid_Votes` — Whole number болсын. Бір жол бір санау аумағына сәйкес келуі керек.
8. Егер CSV түгел бір баған болып ашылса, бөлгішті **Comma** етіп таңдаңыз. Баған атаулары бірінші жолда болса, **Use First Row as Headers** қолданыңыз. Кодтардың бастапқы нөлдерін жоғалтпау үшін оларды мәтін күйінде сақтаңыз.
9. **Close & Apply** басыңыз.

### 5.2. PercentLeave бағаны

`Brexit` кестесін таңдаңыз → **Modeling → New column**:

```dax
PercentLeave = DIVIDE(Brexit[Leave], Brexit[Valid_Votes])
```

**Column tools → Format → Percentage**, ондық орын санын **2** қойыңыз. Формулаға қосымша `* 100` қоспаңыз: Percentage пішімі 0,7556 санын 75,56% ретінде көрсетеді.

Бұл көрсеткіш — **ЕО-дан шығуды қолдаған жарамды дауыстардың үлесі**. Ол сайлауға қатысу пайызы емес. Бөлгішке `Electorate` немесе жарамсыз бюллетеньдер кіретін `Votes_Cast` қолданылмайды.

### 5.3. Топталған нәтижеге арналған өлшемдер

**Modeling → New measure** арқылы әр формуланы бөлек енгізіңіз:

```dax
TotalLeave = SUM(Brexit[Leave])
```

```dax
TotalValidVotes = SUM(Brexit[Valid_Votes])
```

```dax
LeaveShare = DIVIDE([TotalLeave], [TotalValidVotes])
```

`LeaveShare` пішімін де **Percentage, 2 decimal places** етіңіз. Аудан үшін `PercentLeave` мен `LeaveShare` бірдей шығады, егер әр ауданға бір жолдан келсе. Ел немесе жалпы нәтиже үшін **LeaveShare** пайдаланыңыз: ол дауыстар санына қарай дұрыс салмақтайды. Аудандық пайыздардың жай Average мәні жалпы дауыс үлесіне тең емес.

### 5.4. Ең жоғары 10 аудан кестесі

1. **Table** визуалын қосыңыз.
2. Өрістеріне `Brexit[Area]` және `[LeaveShare]` қосыңыз. Тапсырмада жасалған `PercentLeave` бағаны Data view ішінде сақталады; аудандық кестені сонымен де жасауға болады.
3. Визуалды таңдаған күйде **Filters → Filters on this visual → Area** ашыңыз.
4. Filter type — **Top N**; Show items — **Top 10**; By value — **LeaveShare**. **Apply filter** басыңыз.
5. Кестеде `LeaveShare` бағанының тақырыбын басып, **Descending** бойынша сұрыптаңыз. Top N тек таңдауды орындайды, сұрыптауды бөлек тексеріңіз.

### 5.5. Regions анықтамалығы және елдермен байланыс

Тапсырмада архивтегі **Regions** кітабын жүктеу айтылған. Оның мақсаты — әр аймақты England, Wales, Scotland немесе Northern Ireland елімен байланыстыру.

1. **Home → Get data → Excel workbook** арқылы екінші архивтегі Regions анықтамалығын ашыңыз.
2. Оны `Regions` деп атаңыз. Аймақты анықтайтын бағанды `Region`, ел атауын сақтайтын бағанды `Country` деп атаңыз. Нақты деректерді қарап атаңыз; бірінші бағанды автоматты түрде Region деп қабылдамаңыз.
3. Екі кестеде де аймақ коды болса, байланыс үшін кодты қолданыңыз. Кодтар болмаса, бірдей жазылған аймақ атауларын пайдаланыңыз. Әр байланысқан бағанның дерек түрі бірдей болсын.
4. **Model view** ішінде `Regions[Region] → Brexit[Region]` байланысын жасаңыз. Кардиналдылығы — **One to many (1:*)**, сүзгі бағыты — **Single**, байланыс белсенді болсын. Кодпен байланыстырсаңыз, тиісті код бағандарын қолданыңыз.
5. `Regions` жағында әр аймақ бір рет қана тұруы тиіс. Бос мәндер мен артық бос орындарды тазалаңыз. Деректерді жаппай өшірмеңіз.
6. `Regions[Country]` таңдаңыз → **Column tools → Data category → Country/Region**.

Логиканы тексеру үшін:

| Region | Country |
| --- | --- |
| East Midlands, East of England, London, North East, North West, South East, South West, West Midlands, Yorkshire and The Humber | England |
| Scotland | Scotland |
| Wales | Wales |
| Northern Ireland | Northern Ireland |

Архивтегі Regions қолжетімсіз болса, осы бумадағы `RegionCountry_fallback.csv` файлын уақытша анықтамалық ретінде жүктеуге болады. Ондағы аймақ атауларын CSV-дегі нақты атаулармен салыстырыңыз; тапсырманың түпнұсқа Regions кітабын алу мүмкін болса, соны пайдаланыңыз.

**Gibraltar:** толық ресми деректерде бұл аумақ болуы мүмкін. Оны England деп белгілемеңіз және елдік картаға сыйғызу үшін бастапқы деректерден өшірмеңіз. Төрт елдің картасында көрсетілмеуі мүмкін; картадағы қамту мен жалпы нәтиже арасындағы айырманы түсіндіріңіз. Қосалқы анықтамалықта ол бөлек сақталған.

### 5.6. Shape map: тапсырмадағы төрт елдік көрініс

Құжат суретінде England, Wales, Scotland және Northern Ireland аумақтары боялған. Бұл — төрт ел бойынша топталған көрініс; жеке аудандардың бәрін бөлек полигонмен көрсететін карта емес.

1. Егер Shape map визуалы көрінбесе: **File → Options and settings → Options → Preview features → Shape map visual** қосыңыз. Бағдарлама қайта қосуды сұраса, есепті сақтап, Power BI Desktop-ты қайта ашыңыз. Кей нұсқаларда визуал алдын ала қолжетімді болады.
2. **Shape map** қосыңыз.
3. **Location** өрісіне `Regions[Country]`, **Color saturation / Color** мәніне `[LeaveShare]` қойыңыз. Мән әр елге бірдей болып көрінсе, Regions → Brexit байланысын тексеріңіз.
4. **Format visual → Map settings / Shape** ішінен United Kingdom елдерінің шекараларын таңдаңыз, егер ондай дайын карта бар болса. **View map type key** арқылы карта күтетiн атауларды тексеріңіз: олар Country мәндеріне сәйкес келуі керек.
5. Дайын UK картасы болмаса немесе бірдей пішінді пайдаланғыңыз келсе, **Custom map → Add a map** арқылы пакеттегі **UK_countries.topojson** файлын таңдаңыз. Оның `Country` кілттері: `England`, `Wales`, `Scotland`, `Northern Ireland`. `Regions[Country]` осы мәндерге сәйкес келсін. Кездейсоқ басқа елдің әдепкі картасын қалдырмаңыз.
6. Төмен үлеске ашық қызыл, жоғары үлеске қою қызыл түс таңдаңыз. Tooltip ішіне Country, TotalLeave, TotalValidVotes, LeaveShare қосыңыз.
7. Атауын `Brexit: ЕО-дан шығуды қолдаған дауыс үлесі` деп қойыңыз. Түс шкаласының сандық мәндері пайыз ретінде оқылсын.

Қосылған шекара файлы Natural Earth ашық картографиялық деректерінен жасалды: Ұлыбританияның әкімшілік аумақтары төрт ел бойынша біріктіріліп, контурлары ықшамдалды. Геометриялар мен төрт кілт тексерілді; бастапқы сілтеме мен өңдеу сипаттамасы `MAP_SOURCE.json` ішінде. Бұл — елдік шолу картасы, 2016 жылғы аудандық шекаралар жиынтығы емес. Power BI Desktop бұл Linux ортасында іске қосылмағандықтан, импортты өз компьютеріңізде тексеріңіз.

**Shape map ұйымдық баптаумен бұғатталса:** `Filled map` немесе Azure Maps ішіндегі **Filled layer** көмегімен Country бойынша картаны құрып, LeaveShare бойынша түстік шкаланы қойыңыз. Есепте визуал түрін нақты жазыңыз. Егер оқытушы Shape map түрін міндетті десе, оның қосылуын қамтамасыз етіп, жұмысты сол визуалмен толықтырыңыз.

### 5.7. Аудандар бойынша дәлірек карта

Тапсырма мәтінінде аудандық дәлдік сұралады. Сондықтан төрт елдік картамен қатар аудандық картаны бөлек бетке қосу пайдалы. Құжаттағы суретті аудандық карта деп атамаңыз.

1. **New page** қосып, `Аудандық нәтижелер` деп атаңыз.
2. `Brexit` ішінде есептелетін баған жасаңыз:

```dax
AreaCountry =
VAR CountryName = RELATED(Regions[Country])
RETURN
    SWITCH(
        TRUE(),
        Brexit[Area] = "Gibraltar", "Gibraltar",
        ISBLANK(CountryName), BLANK(),
        Brexit[Area] & ", " & CountryName & ", United Kingdom"
    )
```

Бұл формула белсенді `Regions → Brexit` байланысын қажет етеді. Gibraltar бөлек өңделеді. Елмен сәйкеспеген жолдарды бос күйде қалдырмай, алдымен анықтамалықты түзетіңіз.

3. `AreaCountry` үшін **Data category → Place** қойып, геокодтауға негізделген аудандық картада пайдаланыңыз. Орны қате анықталған аудандарды тексеріңіз: ұқсас атаулар мен 2016 жылдан бері өзгерген шекаралар бар.
4. Ең дәл полигондық нұсқа үшін 2016 жылғы санау аумақтарына сәйкес TopoJSON және `Area_Code` бойынша сәйкестендіру қажет. Қазіргі әкімшілік шекараларды 2016 жылғы кодтарға тексермей қосуға болмайды. Дәл шекара жоқ кезде карта дәлдігін асыра сипаттамаңыз.
